Site com HTML semântico e CSS, sem JavaScript, sobre carros elétricos.

## Atividade 1 – HTML e CSS
- Menu de navegação, seções, tabela comparativa, formulário com validação e barra lateral.
- Layout com CSS Grid, responsivo, cores em verde e pêssego.
- Acessibilidade: foco visível, link "pular para o conteúdo" e navegação por teclado.
- Validado no W3C (prints em `prints/`).

## Atividade 2 – SEO
- Título, descrição e link próprio em cada página.
- Configuração básica para compartilhamento nas redes sociais.
- Adicionar favicon ao site.
- Criar `robots.txt` e `sitemap.xml`.
- Criar a segunda página `recarga-de-carro-eletrico.html`, com links entre as páginas.
- Utilizar imagens otimizadas, com texto alternativo (`alt`).
- Documentar as melhorias de SEO no arquivo `SEO.md`.
